# 📖 十一学校国际部 A Level & CNCC 智慧学业与错题本

专为**北京十一学校国际部 (BNDS International Department) A Level 项目**同学量身定制的现代化网页版学业管理与错题复盘系统。

不仅是一个高效的错题本，更是一个**全学科加权成绩追踪、学情诊断与数据可视化分析中心**。全面适配 **A Level 核心学科**（数学【纯数学1 P1、概率与统计1 S1】、物理 9702、经济 9708 等）与 **CNCC 国家课程科目**（地理、生物、化学），并支持自定义学科、单元与考核权重。

---

## ✨ 核心功能亮点

### 1. 📈 加权成绩追踪与多维图表分析中心
- **全维度加权学业总览 (Weighted GPA / Task Grade)**：支持按学科配置考核维度权重（如 Attainment、Course Skills、Learning Behavior、Final），系统在所有页面统一使用**加权综合成绩**（而非简单算术平均），并支持录入 **Curve 后成绩**。
- **历次小考成绩趋势折线图 (Score Trend)**：按时间轴绘制得分率变化，内置 A* (89.5% / 94.5%) 与 A (79.5% / 89.5%) 目标基准线，支持按学科一键切换视图；移动端自动切换为类股票走势的精简日期视图，点击节点即可查看测验详情。
- **全科学业均衡度雷达图 (Competency Radar)**：基于各科加权均分直观对比各科表现，排查偏科与短板。
- **各单元错题与失分分布图 (Unit Breakdown)**、**Task Grade 等级分布环形图 (Doughnut)**、**测验类型对比柱状图 (Type Bar)**：多维度定位薄弱环节，提供**【一键为此薄弱单元组卷重做】**直达按钮。
- **一次考试支持关联多个考查单元 (Multi-Unit Assessment)**：支持多选勾选任意多个考查单元，适配跨单元综合小测。
- **适配十一国际部官方 Task Grade 打分标准**：
  - **A Level 标尺**：89.5%~100% 为 A*，79.5%~89.4% 为 A，69.5%~79.4% 为 B，59.5%~69.4% 为 C，49.5%~59.4% 为 D，40%~49.4% 为 E，0%~39.9% 为 U。
  - **CNCC 标尺**：94.5%~100% 为 A+，89.5%~94.4% 为 A，84.5%~89.4% 为 A-，79.5%~84.4% 为 B，69.5%~79.4% 为 C，59.5%~69.4% 为 D，0%~59.4% 为 F。

### 2. 🤖 AI 智能识题、Mark Scheme 解析与真题题号检索
- **多模型 AI 视觉识题**：支持配置 Gemini / DeepSeek / OpenAI 兼容接口，上传或直接 `Cmd+V` / `Ctrl+V` 粘贴试卷及评分标准截图，自动识别题干、KaTeX 公式、分小问结构、小问间过渡文字、选择题选项及真题卷号。
- **剑桥官方四列表格解析**：自动解析或生成 `Question | Answer | Marks | Guidance` 四列 Mark Scheme，并带有每问总分行。
- **联网 / AI 真题题号检索**：未提供 Mark Scheme 时，可根据题干或截图辅助检索对应的 Past Paper 考卷与题号。

### 3. ✍️ 错题结构化录入、防剧透浏览与解题备注
- **全面题型支持**：
  - **复合大题（分小问）**：支持标记具体失分小问、在小问之间添加过渡说明文字，并支持每个小问独立选择四列表格、自由 Markdown 或跳过题解。
  - **选择题（单选 / 多选）**：首页浏览默认隐藏“当时错选”与“正确答案”标记以防剧透，点击展开解析时再显示。
  - **自由 Markdown 模式**：支持 LaTeX 行内/块级公式及剪贴板截图直接粘贴入库。
- **💡 思路点拨与解题备注**：除标准 Mark Scheme 表格外，额外提供独立的解题备注区（支持 Markdown 与 `$LaTeX$`），专门记录官方步骤未写明的“为什么这样写”与易错提示，在错题详情与组卷解析中同步展示。

### 4. 🖨️ 智能按小问留白组卷与 A4 PDF 导出
- **按学科 & 多选单元一键组卷**：支持多选单元筛选错题，自动生成无答案干扰的 A4 重练试卷（隐藏考点简题与测验来源，真题号简洁展示）。
- **智能按小问留白 + 预览单题微调**：
  - 默认根据小问数量自动分配演算区高度（1~2 问 140px、3 问 240px、4 问及以上 340px+；选择题自动不生成留白区）。
  - 在组卷预览界面中，每道题均支持通过滑块或 `−` / `+` 按钮**实时微调留白高度**（打印与导出 PDF 时控制条自动隐藏）。
- **灵活排版选项**：支持 3 档印刷字号（9.5pt / 10.5pt / 12pt）、单元标签开关，以及可选在卷末另起一页附带 Mark Scheme 与思路备注。

### 5. 📱 多端适配、常驻顶栏与云端/本地同步
- **常驻顶部工具栏**：随时一键切换页面阅读字号（标准 / 适中 / 特大，同步作用于大题与选择题）、快速录入错题、切换深浅色主题，并实时查看同步状态。
- **移动端深度优化**：针对手机端优化了筛选栏换行、测验成绩卡排版、组卷选项与折线图显示。
- **数据安全与多端同步**：支持本地 IndexedDB 离线存储、全量 JSON 导入/导出备份，以及 Supabase 云端同步。AI API Key 与自定义接口地址仅保存在各设备本地，不会同步。云端覆盖功能需先在 Supabase SQL Editor 中应用 `supabase/security.sql`。

## 🚀 启动与使用方式

直接用现代浏览器（Chrome、Safari、Edge 等）打开项目根目录下的 [`index.html`](file:///Users/Delnes/Desktop/Projects/Error%20Notebook/index.html) 即可使用；

或在项目根目录终端中运行轻量本地服务器：
```bash
python3 server.py
```
终端会自动启动本地服务并在默认浏览器中打开应用。
