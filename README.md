# 📖 十一学校国际部 A Level & CNCC 智慧学业与错题本

专为**北京十一学校国际部 (BNDS International Division) A Level 项目**同学量身定制的现代化网页版学业管理与错题复盘系统。

不仅是一个高效的错题本，更是一个**全学科成绩追踪、学情诊断与数据可视化分析中心**。全面适配你正在学习的 **A Level 核心学科**（数学【纯数学1 P1、概率与统计1 S1】、物理 9702、经济 9708）以及必须修读的 **CNCC 国家课程科目**（地理、生物、化学）。支持**单次小考关联多个考查单元、多次小考自动折算 Task Grade、多维数据走势图表与单元专项组卷重练**。

## ✨ 核心功能亮点

### 1. 📈 各科成绩整理与多维图表分析中心
- **各科学业概览卡片 (GPA / Task Grade Overview)**：每门学科当前平均百分比折算分、综合等级（A*、A、B 等）、最新小考成绩、已测次数。点击学科卡片可快速聚焦该学科图表。
- **历次小考成绩趋势走向折线图 (Score Trend)**：按时间轴绘制得分率变化趋势，内置 A* (89.5% 或 94.5%) 与 A (79.5% 或 89.5%) 目标基准线，支持按学科一键切换视图。
- **全科学业均衡度雷达图 (Competency Radar)**：直观对比数学、物理、经济与 CNCC 各科表现，排查偏科与短板。
- **各单元得分率与失分排查横向条形图 (Unit Breakdown)**：将历次考试得分与错题数结合，一眼锁定得分率最低的知识点。
- **Task Grade 等级分布环形图 (Doughnut)**：A* / A / B / C 各等级斩获占比。
- **测验类型对比柱状图 (Type Bar)**：随堂小测 vs 单元大测 vs 作业评估 vs 模拟考表现对比。
- **智能学情诊断与提分行动建议**：自动识别优势学科与薄弱单元，并提供**【一键为此薄弱单元组卷重做】**直达按钮！

### 2. 📝 一次考试支持包含多个考察单元 (Multi-Unit Assessment)
- 国际部平时小测常出现跨单元考察（如同时考《排列组合》与《概率》，或同时考《微分》与《积分》）。
- 录入小考成绩时，单元选择器支持**多选勾选任意多个单元**，并提供“全选”与“清空”快捷操作。
- 考试记录卡片上并列展示所有关联单元标签（如 `📖 [S1] Probability` `📖 [S1] Permutations`）。

### 3. 🎯 适配十一国际部官方 Task Grade 打分标准
- 单科小考每次卷面总分均不同（如 30分、32分、45分等），输入卷面实得分与总分后，系统自动折算为百分制。
- 自动根据十一国际部官方评分标尺匹配 Task Grade：
  - **A Level 标尺**：89.5%~100% 为 A*，79.5%~89.4% 为 A，69.5%~79.4% 为 B，59.5%~69.4% 为 C，49.5%~59.4% 为 D，40%~49.4% 为 E，0%~39.9% 为 U。
  - **CNCC 标尺**：94.5%~100% 为 A+，89.5%~94.4% 为 A，84.5%~89.4% 为 A-，79.5%~84.4% 为 B，69.5%~79.4% 为 C，59.5%~69.4% 为 D，0%~59.4% 为 F。

### 4. 🎯 按单元一键专项精准组卷（备考提分利器！）
- 在“单元重练组卷”页面中，选定学科与单元后，一键生成 `A Level 数学 · [P1] Integration 专项突破重练卷`。
- 支持按需包含详细 Mark Scheme 解析，预留标准演算留白，直接导出 A4 PDF 或打印。

### 5. ✍️ 极致顺手的 LaTeX 公式与剪贴板截图直接粘贴
- 试卷/Past Paper 截图后，在输入框按 `Cmd+V` / `Ctrl+V` 直接粘贴图片，自动转为图片 Markdown 实时渲染。
- 完整支持 KaTeX 数学公式、Mark Scheme 折叠解析防剧透。

### 6. 🌓 深浅色模式自适应与本地完全持久化
- 右上角随心切换深浅色外观，所有图表与公式配色自动同步适配。
- 数据存放于本地浏览器 IndexedDB，离线安全可用，支持一键备份为 JSON 文件。

### 4. ✍️ 极致顺手的 LaTeX 公式与 Past Paper 截图粘贴
- 支持 LaTeX 行内公式 `$y = \frac{16}{x^2}-4$` 与块级公式 `$$\int_2^4 y\,dx$$`。
- Past Paper 题目常带有坐标系图、电路图、几何图：直接在电脑截图后，**在编辑器内按 `Ctrl+V` / `Cmd+V` 即可粘贴**，自动作为题目插图入库！
- 题目与 Mark Scheme（标准评分细则与解析）分离录入，题库浏览默认收起，防剧透。

### 5. 🖨️ 完美适配 A4 试卷打印 / 导出 PDF
- 组卷后一键隐藏答案，预留标准演算留白；
- 可选在文末另起一页附带详细 Mark Scheme 参考解析；
- 浏览器按 `Cmd+P` 即可一键打印或导出高质量无杂质的练习卷。

### 6. 🌓 深浅色模式与本地大容量持久化
- 右上角一键切换黑白模式，公式代码自动高对比反色，夜间刷题不伤眼。
- 基于本地浏览器 IndexedDB 存储，完全私密安全，支持一键导出全量 JSON 备份到网盘。
